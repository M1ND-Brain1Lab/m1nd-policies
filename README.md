# m1nd-policies

The M1ND Impressum, privacy policy (Datenschutzerklärung) and terms of use
(Nutzungsbedingungen), in German and English. The German terms are binding.

Published on GitHub Pages from `main`:
<https://m1nd-brain1lab.github.io/m1nd-policies/>

| Document | Deutsch | English |
|---|---|---|
| Impressum | `impressum.de.html` | `impressum.en.html` |
| Privacy policy | `datenschutzerklaerung.de.html` | `datenschutzerklaerung.en.html` |
| Terms of use | `nutzungsbedingungen.de.html` | `nutzungsbedingungen.en.html` |

Static HTML, no build step. Open any file in a browser to preview it. The
pages are skeletons until the legal text is pasted in (see `CLAUDE.md`).

This repo is the only copy: the app (`app/src/config/legal-links.ts` in
`m1nd`), the store listings, the panel and the website link here, so page
names never change without updating those links in the same release.
